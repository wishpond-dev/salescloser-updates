The call now ends as well as it starts.

Most of this week went into the edges of the call: the first words, the goodbye, and a batch of calls we were wrongly marking as done.

Bot · End of call

It says goodbye once, then hangs up

Some calls were getting stuck repeating the goodbye. Not anymore.

Cumulative end-call attempt counter with a forced hangup cap, post-close timer cancelled, grace extension guarded. Covered by new unit and E2E tests.

The first words always arrive

No more picking up to a silent line.

Queued speech had a TTL, so under load the greeting could expire before it played. TTL disabled; nothing queued gets dropped.

03
Knowledgebase, agents & day-to-day use

We fixed things clients notice but never report.

None of these ever became a support ticket. Clients just quietly lived with them.

Knowledgebase · Encoding

Files can't get stuck “encoding” forever

Last week big files stopped dying mid-index. This week the ones already stranded recover on their own.

The dashboard now detects files stuck mid-encoding and re-queues them, and the encoding worker returns a real job id in its async enqueue response, so every encode is trackable end to end instead of fire-and-forget.

sc-90553dash #1955enc #22
Agents · Create

The form says exactly what's wrong

No more guessing which field the form didn't like.

Field-level validation in the creation modal, server 422s normalized into per-field messages, and collapsed sections auto-expand to show where the error lives.

sc-90265dash #1943
Appointments · SMS

Reminder texts stopped crashing

Prospects get their appointment reminder, every time.

Datetimes with fractional seconds crashed the reminder job silently. Parsing is now tolerant, so the SMS goes out.

Fewer small annoyances

Scale, retention & observability

Built for bigger clients.

Some of this week was for the accounts we're trying to land, and for keeping the ones we have.

Infrastructure · Isolation

A big client can get their own bot stack

Per-client bot endpoints: one account's traffic can be routed to dedicated infrastructure, so heavy usage from one client never slows anyone else's calls. Enterprise prospects ask for exactly this.

Client-level bot endpoint override in the dashboard, resolved at call routing time — no bot deploy needed to move a client onto their own stack.

sc-90606dash #1966
Retention

Cancellations now reach Customer Success

Before this, a client could cancel without anyone talking to them.

Cancellation requests now fire to Zapier for CSM routing, so Customer Success gets the case while there's still a conversation to have. Alert copy tuned to match.

sc-90464dash #1993
Observability

We can see which tool slows a call

When a call drags, we can see exactly which lookup dragged it.

Tool-call latency and count metrics now carry a tool_name label, so a slow CRM lookup or calendar check shows up by name in the dashboards.
