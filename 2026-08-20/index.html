The agent got easier to talk to.

Four senses tuned this week: how it sounds, how it hears, how consistent it stays, and what it sees.

Web calls · Audio

The voice stopped stuttering

Web-call audio plays smoothly, and interrupting the agent cuts it off instantly.

The bot's RTC audio now runs through a real jitter buffer, flushed on barge-in so an interruption does not drain stale audio first.

Avatar calls · Hearing

It hears you over its own ambience

Background ambience no longer deafens the agent to the caller.

Ambience playback was starving the inbound audio consumer, so the agent literally stopped receiving the caller's voice.

Voice · Consistency

One call, one voice

The voice no longer changes mid-call, and quiet callers stop getting the same nudge on repeat.

The TTS cache key was blind to prosody, so a cache hit could answer in the wrong voice. Inactivity follow-ups are deduplicated.

What the caller shows on camera reaches the agent's eyes once more.

LiveKit started delivering frame planes as memoryviews and the frame reader assumed bytes, so vision silently got nothing.
